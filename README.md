# OmniDeck

🇺🇸 **English** | 🇧🇷 [Português](#português)

**OmniDeck** is a next-generation markdown presentation engine. It focuses on the simple generation of high-quality presentations using only markdown with textual content as its source. Unlike traditional presentation tools, OmniDeck is designed to be agentic and agnostic to location: it can import markdown from anywhere on your local computer, including your Obsidian vaults.

## Future Vision
The ultimate evolution of OmniDeck is to host an **AI Agent**. You simply ask the agent to generate a presentation on a topic, and it scans your local folders and vaults, analyzes relevant content, asks you questions to refine the narrative, and generates beautiful slides automatically.

## Tech Stack
- **Frontend**: Vite + Vanilla JS (Presentation renderer)
- **Backend**: Python + FastAPI (Agent engine, local file system reader, LLM orchestrator)

---

<h2 id="português">🇧🇷 Português</h2>

**OmniDeck** é um motor de apresentações markdown de próxima geração. Focado na geração simples de apresentações de alta qualidade, tem como fonte apenas arquivos markdown textuais. Diferente de ferramentas tradicionais, o OmniDeck é focado em ser agêntico: capaz de importar markdowns de qualquer local no seu computador, incluindo seu vault do Obsidian.

## Visão de Futuro
A evolução final do OmniDeck é possuir um **Agente IA**. Você pede para ele gerar uma apresentação sobre um tema, ele varre suas pastas e vaults, analisa conteúdo aderente, faz perguntas para refinar e gera os slides de forma automatizada.

## Stack Tecnológica
- **Frontend**: Vite + Vanilla JS (Motor de renderização e parser de markdown)
- **Backend**: Python + FastAPI (Motor do Agente, leitura de pastas locais e orquestrador LLM)
